Descrição: Este projeto foi desenvolvido em Kotlin e simula o desenvolvimento de um jogo indie. O programa utiliza três recursos principais: Tempo, Dinheiro e Bugs. Durante o desenvolvimento, os recursos são atualizados até que o jogo seja lançado ou que o dinheiro ou o tempo acabem.
Execução: 
1. Abra o projeto em uma IDE compatível com Kotlin.
2. Abra o arquivo `Main.kt`.
3. Execute o programa.
4. Digite os valores solicitados pelo programa.
5. Acompanhe o desenvolvimento do jogo e o resultado apresentado no terminal.
